规范指引

## 一、架构设计原则

### 1.1 高内聚模块设计
- **功能模块化**：按功能划分独立模块（进程管理、内存操作、模式扫描、数据解析等）
- **单一职责**：每个类/函数只负责一个明确的逻辑功能
- **接口抽象**：定义清晰的模块间接口，隐藏内部实现细节

### 1.2 低耦合通信机制
- **事件驱动**：模块间通过事件/消息队列通信
- **依赖注入**：使用接口类而非具体实现，便于单元测试和替换
- **观察者模式**：状态变化时通知相关模块

## 二、多线程架构规范

### 2.1 线程管理框架
```
主线程(UI/控制) ? 线程池 ? 工作线程(内存操作)
          ↑
    监控/日志线程
```

### 2.2 线程安全要求
- **锁粒度控制**：使用读写锁保护共享数据，避免全局锁
- **无锁设计**：读多写少场景考虑原子操作或无锁数据结构
- **线程局部存储**：线程专用数据使用thread_local存储

### 2.3 线程间通信
- **任务队列**：主线程向工作线程投递任务
- **进度通知**：工作线程通过回调或事件报告进度
- **取消机制**：支持安全终止长时间运行的操作

## 三、代码复用性设计

### 3.1 核心抽象层
```cpp
// 平台无关的内存操作接口
class IMemoryOperator {
    virtual bool Read(Address addr, Buffer& buffer) = 0;
    virtual bool Write(Address addr, const Buffer& buffer) = 0;
    virtual ~IMemoryOperator() = default;
};

// 平台特定实现
class WindowsMemoryOperator : public IMemoryOperator { ... };
class LinuxMemoryOperator : public IMemoryOperator { ... };
```

### 3.2 通用组件库
- **内存模式扫描器**：支持多种扫描算法（精确值、范围、模糊值等）
- **数据类型解析器**：统一处理整数、浮点数、字符串等数据格式
- **地址计算器**：处理指针链、偏移计算等通用逻辑

### 3.3 模板元编程应用
```cpp
// 类型安全的数值转换
template<typename T>
class ValueConverter {
public:
    static T FromBytes(const ByteArray& data);
    static ByteArray ToBytes(T value);
};
```

## 四、内存操作安全规范

### 4.1 边界检查
- **地址验证**：所有读写前验证地址有效性
- **缓冲区检查**：确保目标进程缓冲区足够容纳操作
- **权限检查**：确认目标内存区域可读写

### 4.2 异常处理
```cpp
class MemoryOperationException : public std::runtime_error {
    enum ErrorCode {
        ACCESS_VIOLATION,
        INVALID_ADDRESS,
        PROCESS_NOT_FOUND
    };
    // ...
};
```

### 4.3 资源管理
- **RAII原则**：进程句柄、内存映射等资源自动释放
- **智能指针**：使用unique_ptr/shared_ptr管理动态资源
- **作用域锁**：使用lock_guard/unique_lock自动管理锁

## 五、代码可读性与维护性

### 5.1 注释规范
```cpp
/**
 * @brief 从目标进程读取指定地址的内存
 * @param processId 目标进程ID
 * @param address 要读取的虚拟地址
 * @param buffer 接收数据的缓冲区
 * @param size 要读取的字节数
 * @return 成功读取的字节数，-1表示失败
 * @throws MemoryOperationException 当操作失败时抛出
 * @note 调用前确保目标进程有相应内存区域的读取权限
 * @warning 不验证地址有效性，调用者需自行检查
 */
ssize_t ReadProcessMemory(pid_t processId, 
                         uintptr_t address,
                         void* buffer,
                         size_t size);
```

### 5.2 配置与常量
- **魔法数字**：禁止在代码中直接使用，定义为命名常量
- **配置文件**：扫描参数、内存模式等可配置化
- **枚举类型**：操作类型、错误码等使用强类型枚举
